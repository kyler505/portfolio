# Skill icons

Brand SVGs (all except langgraph and the generic icons): Devicon v2.17.0,
https://github.com/devicons/devicon/tree/v2.17.0, under the included MIT license.

langgraph.svg: Simple Icons 16.0.0,
https://github.com/simple-icons/simple-icons/tree/16.0.0, under the included CC0 license.

code.svg, database.svg, terminal.svg, network.svg, and cluster.svg are
original generic symbols, used for COBOL, SQL, the terminal crates, iroh,
and Slurm. They are not presented as those projects' official logos.

Icons are decorative; the adjacent text names each skill. All assets are served
locally through the existing Trunk previews copy rule.
